# 一、1EHV — 同人志 / 画集 / 3D 生成

## 1.1 顶层分类

| 目录 | 说明 |
|------|------|
| `[作者名]` 或 `[作者名 (罗马字)]` | 标准作者/社团目录，如 `[08BASE (東山エイト)]`、`[あんみつよもぎ亭 (みちきんぐ)]` |
| `[01杂]` | 杂项（预留，通常为空） |
| `[03gen]` | AI 生成 / 3D 渲染 / 第三方生成作品 |

## 1.2 作者内部子分类

按子目录编号归类（作者目录下可能的部分子集）：

```
1. 同人志/             # 同人志作品
2. 商业志/             # 商业杂志/单行本连载
3. 单行本/             # 单行本（整本）
4. 画集/               # 画集・插画合集
```

也可扩展为带副标题的子目录格式：
```
2. 同人志・Victim Girls/   # 特定系列归类
```

## 1.3 文件命名规范

### 标准年/月/日格式
```
(YYYY.MM.DD) 标题 [汉化组][作者].zip
(YYYY.MM) 标题 [FANBOX] [作品系列] [汉化组][作者].zip
```

示例：
```
(2018.04.25) 試着室での〇〇はご遠慮ください！ [kou2014 重嵌][08BASE (東山エイト)].zip
(2024.08.03) 佐藤さんのアブノーマルお仕事 [空気系☆漢化][08BASE (東山エイト)].zip
```

### Comiket（CXX）格式
```
(CXX) 标题 [作品系列] [汉化组][作者].zip
```

示例：
```
(C100) 好きな子のバイト先が H なサービスをシている 2 [空気系☆漢化][08BASE (東山エイト)].zip
(C102) ムツキは大人の遊びがしたい [ブルーアーカイブ] [山樱汉化][Deadnoodles (ゴミョン)].zip
```

### 期刊/杂志格式
```
(COMIC 杂志名 YYYY 年 M 月号) 标题 [汉化组][作者].zip
```

示例：
```
(COMIC BAVEL 2026 年 2 月号) 元カノの妹と付き合うわけない [DL 版] [中国翻訳][▲ちまき].zip
```

### 画集/合集格式
- 源平台 + `作品集` + `[日期]` + `[作者]`
```
PIXIV 全投稿作品集 2024.12.26 [08BASE (東山エイト)].zip
FANBOX 作品集 [08BASE (東山エイト)].zip
TWITTER 作品集 [自整理 1598P 截止 2025.06.03][Fatalpulse (朝凪)].zip
```

### 标签顺序约定
```
(事件/日期) 原标题 [汉化组/来源][DL版/無修正等标记][作者].zip
```

## 1.4 [03gen] — AI 生成 / 3D 渲染

### 顶层结构
```
[03gen]/
├─ [作者名]/                    # 按作者名建目录
├─ *.zip                        # 也有直接散落的 zip 文件
```

### 子目录命名方式（多种风格）：
- **日期范围型**: `2025.4-7/`, `11(2025）~2(2026）/`, `24.10-24.11/`
- **截止日期型**: `lyosis截止至2026.1.30/`, `2月6更新/`
- **Pixiv 导出型**: `[PIXIV]/`

### 文件命名方式（多种风格）：
1. **编号 + 角色名 + (作品名)**: `581 mika (blue archive).zip`
2. **Pixiv 导出**: `[PIXIV] 作者名 [PixivID] [AI Generated] [数量].zip`
3. **单角色名**: `asuka.zip`, `marin.zip`
4. **原始 ID**: `3686518_c551423c09.zip`

# 二、[02COS] — Cosplay 归档

## 2.1 顶层分类

| 目录/文件 | 说明 |
|-----------|------|
| `[Cosplayer名]` | 标准 coser 目录，支持中/日/韩/英/含 emoji 等 |
| `[#stirrup]` | 聚合/搬运整理（非原拍，来源多个 coser） |
| `[02杂]` | 按来源平台整理的杂项内容 |
| `[02COS]_config.json` | 归档配置信息 |
| `coserlist.txt` | 全部 coser 目录名列表（索引） |
| `duplicate_videos.txt` | 重复视频记录 |

## 2.2 文件命名规范

### A. 含作品/角色信息的标准格式
```
(作品名・角色名) 套图描述 [Cosplayer名].zip
(作品名・角色名 #风格/变体) 套图描述 [Cosplayer名].zip
```

示例：
```
(Fate/Grand Order · 阿尔托莉雅[Alter]#女仆) 黑枪呆女仆 [阿半今天很开心].zip
(崩坏：星穹铁道・花火 #性感) 077. [34P-444MB][Arty 亚缇].zip
(碧蓝航线・天狼星 #旗袍) 081. [45P-74.6MB][Arty 亚缇].zip
```

### B. 编号套系格式
```
Cosplayer名 NO.XXX 主题描述 [数量P数量V-大小]
```

示例：
```
蜜汁猫裘 NO.000 圣诞2020 [34P 70MB].zip
蜜汁猫裘 NO.001 巫女 [32P-545MB].zip
蜜汁猫裘 NO.121 柴郡花嫁 [134P2V 8.26GB]/
```

编号套系可能为 `.zip` 文件或目录（目录内含 `正片.zip` `自拍.zip` 等分卷）。

### C. 纯编号格式
```
NN[Cosplayer名].zip
```

示例：
```
01[Reng].zip
02[Reng].zip
```

### D. 日期目录结构
```
YYYY-MM/ 或 YYYY·MM/
├─ (作品名・角色名) 描述 [Cosplayer].zip
├─ (作品名・角色名) NN. 角色名 [Cosplayer].zip
```

### E. 聚合/搬运（[#stirrup]）格式
```
(作品名・角色名 #风格) 描述 [#stirrup].zip
```

# 三、通用规则

## 3.1 目录命名约束
- 目录名统一用 `[名称]` 方括号包裹（顶层和 coser 名）
- 作者名/社团名如有罗马字须用 `()` 注明：`[08BASE (東山エイト)]`
- 禁止非法字符：`/` `\` `:` `*` `?` `"` `<` `>` `|`

## 3.2 扩展名与特殊标记

### 合法扩展名（允许但不限于）
`.zip`, `.mp4`, `.avif`, **`.wbp`**, `.jpg`, `.png`, `.gif`, `.ass`, `.nfo`, `.csv`, `.txt`, `.py`

> `.wbp` 为动态壁纸/动态立绘格式，与 `.zip` 为同一内容的两种封装形式。

### 特殊文件名前缀
- `simi___set_NNN.zip` / `simi___set_NNN.wbp` — simi 工具导出的 FANBOX/Pixiv 分段打包文件
- `A(NP).zip`, `B(NP).zip` — 同一投稿的不同章节/视角分卷（NP = 页数）
- `[#dyna]` — 动态图标识（Live2D / Spine / 动态壁纸），如 `[#dyna]A(13P).wbp`
- `group_abc.py` — 作者自用的批处理脚本，保持原样不动

### 文件名约束
- 扩展名必须位于文件名末尾，禁止在扩展名后追加任何内容
- 文件名长度预估不超过 255 字符
- 元数据标签（汉化组、DL版、無修正、作者等）统一用 `[]` 包裹后置

## 3.3 JSON 配置格式参考（[02COS]_config.json）
标准属性：
```json
{
  "dir": "",
  "children": [
    {
      "name": "[coser名]",
      "count": N,
      "compress": "none|rar|zip",
      "type": "cos|photo|video",
      "children": [...]
    }
  ]
}
```

## 3.4 trename CLI 使用

### scan 扫描生成 JSON
```bash
# 输出到文件（推荐）
trename scan -o output.json "目录路径"

# 输出到剪贴板（默认）
trename scan "目录路径"

# 支持扫描多个目录合并输出
trename scan -o output.json "目录1" "目录2"
```

### scan 关键选项
| 选项 | 说明 |
|------|------|
| `-o, --output PATH` | 输出到文件而非剪贴板 |
| `--include-root` | 将目录本身作为根节点（默认 true） |
| `--hidden` | 包含隐藏文件 |
| `-e, --exclude TEXT` | 排除的扩展名，逗号分隔 |
| `-x, --exclude-pattern TEXT` | 排除文件名模式：`processed`（已处理格式）、`numbered`（编号格式）、或自定义正则 |
| `--mode [normal\|leak]` | 扫描模式：`normal`=常规；`leak`=泄漏模式（读取 `trename_config.toml`） |
| `-s, --split INTEGER` | 分段行数（0=不分段，默认1000） |
| `-c, --compact` | 紧凑格式（文件单行） |

### rename 执行重命名
```bash
trename rename "output.json"
```

### undo 撤销
```bash
trename undo
```
