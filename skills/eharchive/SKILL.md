# EH Archive

Use this skill for classifying, naming, scanning, and maintaining the user's 1EHV and 02COS archives.

## Workflow

1. Identify the library: `1EHV` for doujinshi, artbooks, and 3D/AI works; `02COS` for cosplay.
2. Preserve source, creator, work, date, and series information when it is available.
3. Apply the matching folder and filename convention from [the detailed rules](references/eharchive-original.md).
4. Treat uncertain metadata conservatively; do not invent creator or work names.
5. Use `trename` for scanning, previewing, applying, and undoing bulk rename operations.

## Safety

- Prefer a scan or preview before changing filenames.
- Keep aggregation and transport sources under the documented `[#stirrup]` convention.
- Preserve unknown files and metadata for manual review instead of forcing a category.

Read the reference file when a naming, category, JSON, or CLI detail is required.
