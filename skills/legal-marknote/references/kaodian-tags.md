# 考点 tag 词汇表（闪卡继承）

用途：`legal-marknote` 与 `legal-goldquest` 给考点锚块、题目标题打思源原生 tag 时，**优先逐字复用本表中的完整路径**——按考点名（路径末段）精确匹配，命中即原样使用，不得为已有考点另造同义路径。

## 结构约定

- 形如 `法考/<科目>[/<专题>]/<考点>`，层级间用 `/`，不含空格；实测层级 3-6 层均有（专题层可省略，如 `法考/民法/物权`）。
- 科目取值以本表实际出现为准：民法、刑法、刑诉、民诉、商经知、行政法、理论法、三国法（另有一条例外 `法考/国际经济法/…`，原样保留）。
- 新建 tag 时科目沿用上列写法，专题层优先沿用同科目既有专题名。

## 重新提取（闪卡更新后刷新本表）

两个来源合并，缺一不可：

1. **30-闪卡 镜像文件（主源，覆盖全部块级 tag）**：全盘搜 `D:/1STUDY/3-Resource/法考` 下所有 `30-闪卡` 目录（精讲卷、背诵卷下都有；正则抓 `#法考/…#` 去重）。
2. **思源卡片化块（补缺）**：没有本地镜像的卡片只存在于思源（如民诉金题卡片），用 `siyuan sql "SELECT tag, COUNT(*) AS n FROM blocks WHERE ial LIKE '%custom-riff-decks%' AND tag != '' GROUP BY tag" -w "D:\1STUDY\SIYUAN" -l 10000 -f json` 抓 `#法考/…#`。坑：运行中内核的 blocks 索引滞后于 CLI 直接写入的闪卡，**必须用 CLI 离线查，不要走运行内核 HTTP API**。
