# 考点 tag 词汇表(闪卡继承)

来源:思源闪卡块(`custom-riff-decks` 属性 + `#法考/…#` 行内标签)中已存在的考点 tag 快照。
用途:`legal-marknote` 与 `legal-goldquest` 给考点锚块、题目标题打思源原生 tag 时,**优先逐字复用本表中的完整路径**——按考点名(路径末段)精确匹配,命中即原样使用,不得为已有考点另造同义路径。

## 结构约定

- 形如 `法考/<科目>[/<专题>]/<考点>#`,各层之间用 `/`,不含空格、不含 `#`(结尾定界符除外)。
- 合法科目(沿用闪卡既有写法,新建 tag 必须从中取):`民法`、`刑法`、`刑诉`、`民诉`、`行政法`、`理论法`、`三国法`。
- 专题层可省略(如 `法考/民法/物权`、`法考/三国法/域外管辖`);新建时优先沿用同科目既有专题名。
- 数字为闪卡引用次数,仅表示覆盖度,与选择无关。

## 重新提取(闪卡更新后刷新本表)

闪卡可能由 `siyuan` CLI 直接写入磁盘,而运行中的内核索引滞后——**用 CLI 离线查询,不要走运行内核的 HTTP API**:

```sh
siyuan sql "SELECT tag, COUNT(*) AS n FROM blocks WHERE ial LIKE '%custom-riff-decks%' AND tag != '' GROUP BY tag" -w "D:\1STUDY\SIYUAN" -l 10000 -f json
```

取返回 JSON 中 `tag` 字段里所有 `#法考/…#` 标记,去重后按科目更新下表。
