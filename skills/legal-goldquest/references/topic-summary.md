# 真金题前置考点总结

本 reference 只在 GoldQuest 生成专题型真金题文档时读取。它定义题目前置的复习导航，不改变题目、选项、答案与解析契约。

## 触发路由

生成前置总结的条件至少满足一项，并且输出属于专题型文档：

- 目标路径或用户任务明确指向 `03-真金题`、真金题合集、专题题库或同专题多题汇编；
- 用户要求“考点总结”“考点必背”“复习导航”或等价的题目前置知识概览。

普通单题整理、只整理一题的 GoldQuest 输出，以及正式 DAMO 闪卡输出不加载本 reference。若文档只包含一题且用户未要求导航，保持现有 GoldQuest 骨架。

## 固定位置

把总结放在根 H1 及根级 provider IAL 之后、第一道 `#####` 题目之前：

```md
# 06 专题六 共同诉讼
{: custom-qb-note-topic-id="civil-procedure-joint-litigation" ...}

## 📌 考点必背
...

##### 73.
...
```

总结只能是根文档的导航区。不要把它插入题目之间、题干、答案区或某道题的 IAL 范围内。

## 内容抽取

先建立“题目 → 考点 → 源规则”映射，再写总结。允许的材料来源按优先级排列：

1. 当前文档题目 IAL 中的 `custom-qb-question-topic-ids`、题干、选项和解析；
2. 同专题的 `20-整理`、`25-kramdown` 或用户提供的源笔记；
3. 与题目明确关联的法条、司法解释、表格和图片文字。

每个总结小节必须能回指至少一道题或源笔记的一段规则。优先沿用源笔记已有标题和术语；不能凭记忆补入材料没有确认的期限、例外、案例结论或数字。题干中的人物、金额、日期和偶然事实只有在它们承载可迁移规则时才进入总结。

总结应覆盖当前题组实际涉及的主要考点，而不是把题目标题逐项罗列或复制完整解析。优先提炼：

- 核心定义、成立要件和制度边界；
- 可横向区分的对象、主体、程序或法律效果；
- 有先后关系的程序步骤、期间和判断路径；
- 例外、限制、绝对化陷阱与易错对照。

## 推荐结构

使用一个稳定的 `## 📌 考点必背`，下面按独立召回单元编号。小节标题采用源笔记术语，不另造抽象栏目：

```md
## 📌 考点必背

### 1. 必要共同诉讼与普通共同诉讼

- **核心区分**：诉讼标的是否同一。
    - 必要共同诉讼：一个诉讼标的，原则上合并审理。
    - 普通共同诉讼：数个同种类诉讼标的，经同意并适宜时合并审理。
- **法律效果**：前者的诉讼行为原则上及于全体；后者各共同诉讼人相互独立。

### 2. 代表人诉讼的程序路径

1. 法院公告并通知权利人登记。
2. 登记权利人推选代表人；推选不成时依材料所载规则协商或指定。
3. 判决效力按是否登记及是否另行起诉分别判断。
```

选择载体服从语义，而不是凑格式：

- 有先后、条件或程序顺序时使用有序列表；
- 只有真正横向比较时使用小表，并遵守现有 GoldQuest 表格门禁；
- 主体关系或多分支判断确实难以线性阅读时，才加入 Mermaid；图只画总结中的关系，不能替代规则文字；
- 要件、例外和法律效果可使用嵌套列表或性质准确的 Callout；样式、颜色和可视化规范继续读取 GoldQuest 现有 references。

总结的颜色、背景、加粗、列表、表格、Callout、Mermaid 和来源保真规则与正文解析完全共用，不在此重复定义。需要样式时读取 [`color-system.md`](color-system.md) 和 [`format-playbook.md`](format-playbook.md)。

## 边界与排除

总结不生成正式题目、选项、`custom-qb-id`、`custom-qb-answer`、答案区 IAL 或任何 `custom-dm-*`、Riff、SRS 字段。考点导航不创建新的 `custom-qb-question-topic-ids`；它只解释现有题目引用的考点。

不要把一题的完整解析复制到总结，也不要为了填满总结而纳入未被题组或源笔记支持的知识。案例材料本身不制作成闪卡；总结只能提取其中有独立、可迁移规则的知识点。

## 完成条件

专题真金题文档交付前逐项确认：

- `## 📌 考点必背` 位于根 provider IAL 之后、第一道 H5 题目之前；
- 总结覆盖题组实际涉及的主要考点，每个小节至少映射一道题或一段源规则；
- 标题和术语优先继承源笔记，未确认的法律内容没有被补写；
- 顺序、流程和阶段使用有序列表，比较任务才使用表格，复杂关系才使用 Mermaid；
- 总结没有题目 IAL、答案 IAL、闪卡属性或运行时 SRS 字段；
- 总结与题目解析不矛盾，且没有把偶然案例事实误写成一般规则；
- GoldQuest strict validator 通过：`E634-E637` 已确认总结存在、位置正确、唯一且没有题目/答案/闪卡字段；题目、选项、答案、解析及原有样式门禁仍全部通过。
