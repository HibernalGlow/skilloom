# 补充篇 C：情境因果锁、八维补全与画布选择

> 方法论吸收自外部 Anima 生图技能（出处见 `11-external-skills.md`），已按**故事板"一页一瞬"**改写。
> 用途：让每一页不只是"标签堆叠"，而是**有因有果的一个瞬间**；并用八维做查漏补缺。

---

## 13.1 情境因果锁（每页先想因果，再写标签）

写任何一页之前，先在内部过一遍这条链（**不向用户输出推理过程**）：

```
发生了什么 → 角色当时的情绪/欲望/冲突 → 具体反应（表情 + 肢体）→ 环境如何参与 → 最抓人的那一瞬间
```

- **先定情境，再选 tags 和 caption**。顺序反了就会写成"姿势 + 表情"的清单。
- 链上必须**有因果**：事件起因 → 角色反应 → **可见后果**。
- **只取一个最有张力的瞬间**，不要在一页里描述连续剧情（连续剧情交给跨页递进，见 §4.9）。
- 即使是单人页也要有内在张力。
  例：偷偷穿上大衣 → 体温升高、心跳变快 → 颤抖 + 脸红 + 攥紧衣襟。
- 涩图同理：**下流动作为因 → 表情/姿态/体液为果**。

### 因果可见性检查（写作时逐条过）

| 规则 | 说明 |
|------|------|
| 每个关键动作至少产生一个可见后果 | 动作 → 衣服移位 / 皮肤泛红 / 液体 / 颤抖 / 视线偏移 |
| 环境事件必须影响角色或画面 | 风 → 头发与布料方向；雨 → 打湿与反光；光 → 塑形与阴影 |
| 情绪必须落到可见处 | 表情 / 视线 / 手势 / 身体重心 / 角色间距离变化 |
| 手部动作必须写明接触对象与位置 | 谁的手、碰哪里、结果如何（仅写 `hand on hip` 不够） |
| 天气/季节不能只写 tag | 必须落到可见物理效果（打湿、积雪、花瓣扑脸、呼出白气） |
| 看不见后果的动作不写 | 无法明确归属的动作改写成 caption 里的自然语言 |

## 13.2 画面八维补全（查漏，不是创作模板）

因果锁定完后，用八维**检查有没有明显空缺**。不是每维都必须写满，但**至少触发 3 维以上**。

| 维度 | 检查问题 | 缺失表现 | 补全方向 |
|------|---------|---------|---------|
| **互动** | 元素之间有行为联系吗？ | 各自摆 pose，零交集 | 对视、触碰、动作呼应、人与环境互动、物体间物理关系 |
| **情感** | 表情 + 肢体传递了什么情绪？ | 通用 smile / 面无表情 | 微表情（惊讶的窃笑、温柔凝视）、身体语言（前倾/缩肩/攥拳） |
| **视线** | 目光或引导线指向哪里？ | 所有人看镜头或闭眼 | 角色间对视、偷瞄、看向画外某物、视线跟随、构图引导线 |
| **联动** | 环境是否影响主体？ | 环境只是纯背景装饰 | 风 → 反应；光 → 塑形；季节 → 细节；材质受环境影响（打湿/反光/积雪） |
| **动势** | 冻结画面暗示了运动吗？ | 像摆拍立绘，重心正中 | 重心偏移、布料飞扬方向、头发飘动、飞溅/飘落轨迹、失衡感 |
| **空间** | 有前后层次和呼吸感吗？ | 平铺直叙，贴脸输出 | 前景遮挡、景深虚化、正负空间、引导线、画面重心偏移 |
| **质感** | 材质有真实细节吗？ | 塑料感 / 卡通化 | 湿润反光、粗糙纹理、丝滑垂坠、水珠凝结 |
| **因果** | 观众能看出前因后果吗？ | 不知道在发生什么 | 行为起因 → 当前姿态 → 暗示后续 |

### 补全纪律

- 补全内容必须**服务于已有因果链**，不能凭空插入与情境无关的元素。
- **单人页**：互动维转为"主体与环境互动"（风吹头发、踩水溅起、光影打在脸侧）。
- **nltags / caption 是补全八维的主要载体**；`[tags]` 保持身份锚点与关键元素干净。
- 补完复查：`[tags]` 与 `[caption]` 是否**语义不重复**（同一概念只放一处）。

## 13.3 画布 / 分辨率选择

> 画布必须匹配构图，**不默认竖图/方图**。先定比例，再定分辨率；默认使用 **1536 级**画布。
> 多人、复杂互动、大场景、强光影或脸部易糊时，可在**同一比例**下升到 2048 级；不得为"默认高清"强行升分辨率。

| 比例 | 画布 | 用途 |
|------|------|------|
| 2:3 | 1024×1536 | 单人全身、立绘、手机壁纸 |
| 3:4 | 1152×1536 | 角色为主、轻环境 |
| 1:1 | 1024×1024 | 头像、半身、简单中心 |
| 1:1 | 1536×1536 | 复杂中心构图、方形海报 |
| 4:3 | 1536×1152 | 室内中景 |
| 3:2 | 1536×1024 | 多人互动、横向动作 |
| 16:9 | 1536×864 | 宽银幕、远景 |
| 9:16 | 864×1536 | 手机海报、竖向空间 |
| 2:1 | 1536×768 | 超宽场景 |
| 1:2 | 768×1536 | 超竖图 |

**Cosmos VAE 约束**：宽高须对齐到 **16 的倍数**，自定义像素时务必检查。

## 13.4 caption 的空间-叙事句式（`Place / Use / Keep / Frame / Light / Blur`）

故事板的 `[caption]` 承担外部技能里 `nltags_block` 的职责：句子级描述负责**空间、动作归属、接触、
视线、遮挡、光源、景深、色彩氛围、因果后果**。

| 职责 | 句式骨架 |
|------|---------|
| 空间 | `Place <主体> ... on the left / right / centre / midground.` |
| 镜头 | `Use a close-up two-shot focused on ...` / `Frame the scene from a low angle ...` |
| 光线 | `Light the scene with soft window light from the left.` |
| 景深 | `Keep <主体> sharp; blur the background into a shallow haze.` |
| 可读性 | `Keep both faces sharp and clearly separated.` |
| 因果 | `As <事件>, <角色> <可见反应>.` |
| 色彩 | `A cool blue-and-white palette ...` |

### 写法纪律

- **不重复**已经在 `[tags]` 里写过的外观/服装硬锚点。
- 每句必须承担明确画面职责；**删掉不改变画面的句子**。
- 允许长句，但必须**可视化、可执行**；不写世界观解释、心理活动、纯文学比喻。
- 允许写：位置、接触、归属、遮挡、视线、主体可读性、因果链、色彩氛围。
- 禁止：离散 tag 列表、代词（本技能 §5.4 强制）、跨页指涉、对话引用。

> ⚠️ **与外部技能的唯一格式差异**：外部技能用 `Place/Use/Keep/Frame/Light/Blur` 写独立的 nltags 段落；
> 本技能把它**融进 `[caption]`**，仍然是客观描述风格、仍然逐行对应 tag（§5.4-F）。
> 不要因为借用句式就破坏"tag ↔ caption 强制对应"和"禁用代词"两条硬规则。

---

## 13.5 每页定稿前的三点确认

1. **因果**：这一页"因是什么、果在哪"能一句话说出来吗？
2. **八维**：至少触发了 3 维不是空缺吗？
3. **分离**：`[tags]` 与 `[caption]` 有没有语义重复？重复就删一处。
