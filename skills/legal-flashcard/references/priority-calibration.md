# 闪卡优先级校准

在普通模式标记候选或专门制卡模式接受卡片时读取本 reference。优先级表达当前源文范围内的相对复习价值，不是知识类型、卡型、renderer 或答案长度的固定映射。

## 相对判断

先从原文建立候选全集，再比较候选。综合判断原文强调程度、对做题结论的影响、混淆与遗忘风险、知识的独立性，以及它与其他规则的依赖关系。相同类型的两条规则可以处于不同优先级；口诀、定义、程序、例外或法律效果本身都不自动获得某一级。

- `P1`：本范围内复习紧迫性最高的一层。
- `P2`：明显值得优先复习，但证据强度低于本范围的 P1。
- `P3`：有独立复习价值，重要性或遗忘代价低于 P2。
- `P4`：仍值得保留为卡，但在本范围内复习收益最低。

`P4` 是有效卡的低优先级，不是拒绝桶。没有独立召回价值的内容仍按 `duplicate`、`unsupported`、`over-budget` 等理由拒绝。

## 校准流程

1. 在 source-fact ledger 中为每个候选记录源定位、原文强调信号、做题作用、遗忘风险和依赖关系，先不定级。完成条件：每个候选都有可回查的原文证据，或因证据不足被明确阻断。
2. 在同一文档或同一明确 source range 内把候选按综合复习价值排序，再选择能够真实区分复习顺序的分界点。不要先给每类知识预设等级，也不要为了填满四级而改写判断。完成条件：任意相邻等级之间都能用原文证据解释为什么上一级应先复习。
3. 逐张做反事实检查：P1 必须能说明为什么高于 P2；P2 必须能说明为什么不是 P3；P3 必须能说明为什么仍高于 P4；P4 必须仍具有保留价值。拿不准不等于 P2：回到原文比较，证据较弱时下调，源边界无法判断时报告 `missing-priority`。完成条件：没有任何卡以“常规”“一般重要”或默认值作为唯一理由。
4. 统计 P1-P4 分布并检查集中现象。小卡组可以只使用部分等级；大卡组缺少低优先级或 P2 占多数时，重新检查原文证据，但不要为消除 validator 警告机械重分配。完成条件：每个分布警告都有 `keep` 或 `revise` 处置及原文理由。

当用户给出明确优先级时保留它，除非它与当前源范围明显冲突；冲突时报告差异并等待选择。卡量预算按校准后的相对顺序截断，不能先把大量候选塞入 P2 再随机删卡。
