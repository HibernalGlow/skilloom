# 原著文风蒸馏与风格锚定引擎 (Author Style Distiller)

> 本文件是 `author-erotic-mastery` 技能的专项深入参考文件。当且仅当进行**已有作品续写、同人文二创、提取特定原作者文风（Style Profile）并进行精准语感约束**时加载。

---

## 一、核心哲学：从“感觉模仿”到“可执行资产约束”

普通 AI 续写最大的失败，是每次都让模型“凭感觉”模仿文风，导致写着写着就滑回了通用 AI 说明书腔调。
真正的文风保持，必须经过：**文本样本 → 16维文风蒸馏 → 结构化 Style Profile 档案（YAML/JSON）→ 运行时强校验**。

---

## 二、十六维文风蒸馏指标体系 (The 16-Dimension Distillation)

提取原著风格时，严禁输出“文笔优美、生动传神”等空洞废话，必须量化以下 16 个具体特征：

| 维度编号 | 维度名称 | 诊断与提炼标准 |
|---|---|---|
| **D01** | **句式平均长度与呼吸感** | 短句（<15字）与长句比例；是否在情绪高潮处切断为极短句；标点符号断句习惯。 |
| **D02** | **视角与视线焦距 (POV Depth)** | 第三人称紧跟限制视角还是半全知；主角内心推演与外在神态的篇幅配比。 |
| **D03** | **对白与行动交织节拍** | 对白是否带有日常微瑕疵、反诘、娇嗔；有无轮流报幕感；动作是否打乱语言节奏。 |
| **D04** | **感官镜头聚焦偏好** | 视觉镜头最常停留在哪里（足踝、裙摆褶皱、领口锁骨、室内光影与温差）。 |
| **D05** | **情感冷热度与推拉厚度** | 情绪是直白宣泄还是克制隐忍；嘴硬心软（傲娇）的推延回合数。 |
| **D06** | **环境与物件的情绪承载度** | 拖鞋、冰棍、沙发靠垫、空调遥控器等生活琐碎是否作为推动亲密关系的道具。 |
| **D07** | **词汇密度与高级口语化** | 口语词、反讽词、生活化隐喻的出现频率；生僻书面词的抑制率。 |
| **D08** | **段落留白与换行习惯** | 单句成段的频率；段落长短是否有强烈的节奏起伏。 |
| **D09** | **阻尼感与欲望递进节奏** | 欲望从眼神到肢体接触的阻力层数（通常需经过 3～4 层微小的日常摩擦才爆发）。 |
| **D10** | **幽默与戏谑的底色** | 男主是否带有从容沉稳的冷幽默；在面对女主发难时如何以四两拨千斤化解。 |
| **D11** | **前中后期文风漂移 (Drift Tracking)**| 原作前期、中期、后期在对白密度和叙事紧凑度上的演变规律。 |
| **D12** | **禁用词与风格违和黑名单**| 哪些词汇一旦出现就会瞬间毁掉原作质感（如中二日式独白、网文翻译腔）。 |
| **D13** | **私密身体细节的修辞偏好**| 如踩脚带收口、足穴温热、足弓软肉凹陷等专属修辞词汇映射。 |
| **D14** | **心理独白与外在表象的反差**| 表层对话的从容 vs 深层心智的精密盘算。 |
| **D15** | **配角出场与生活化烟火气**| 周围日常市井生活对二人世界的掩映与保护。 |
| **D16** | **章末悬念与留白收束方式**| 是以生活化的轻声调笑收尾，还是停留在肢体微动作的凝固瞬间。 |

## 三、文风资产落地模板：`style_profile.yaml`

每次为一部具体小说提炼完风格后，生成保存在项目的 `references/style_profile.yaml` 中，作为每次写作的强校验资产：

```yaml
style_profile:
  author_id: "原作作者标识"
  narrative_core:
    pov: "第三人称主角限制视角（男主），内外双层心智推演"
    sentence_style: "短句为主，长短句错落交织，微讽戏谑，极强空气感"
    sensory_focus: "足踝、足心系带、裙摆空气感、微汗体温、空调室内温差"
  dialogue_mechanics:
    tension: "推拉反诘、生活化斗嘴、言语占上风但肢体被动攻陷"
    forbidden_tics: ["不是...而是...", "这一刻他知道...", "中二括号独白", "滥用破折号"]
  erotic_pacing:
    layers: "日常琐事摩擦(L1) -> 肢体微动态试探(L2) -> 踩脚带成箍(L3) -> 开宫突破(L4) -> 痉挛锁精(L5)"
    diction: "严禁'袜筒/布带'，采用'足心那道窄窄的雪白系带'、'顺着足弓微陷边缘'"
```

## 四、运行时自审与文风门禁 (Style Gate)

写完新章节正文后，模型必须对照 `style_profile.yaml` 进行 5 项硬性自审：
1. **词汇审计**：全文是否出现了违禁词？是否破坏了原作作者的语言底色？
2. **句式审计**：是否有多处句式雷同或连续 3 句以上的工整排比？若有，打散重排。
3. **神态审计**：主角面对女主时，是否保持了原作特有的从容戏谑与长辈般包容，而非变形为急色狂徒或无脑霸总？
4. **工业参数审计（绝对封杀 XX D）**：全文是否出现了诸如“40D/50D/60D”等丝袜厚度商品工业参数？若有，必须 100% 抹除并替换为视觉、厚薄、微绒与肉色透光的文学感官白描。
5. **题材语境审计（封杀玄幻修仙/科幻系统词）**：全文是否滑入了“纯阳罡气/天道/浩瀚威压/天灵盖/倒吸凉气/逻辑破损 87%”等修真玄幻或科幻大词？若有，必须立刻重置，严格捍卫原著轻松、骚浪、调侃、直奔下三路的日系轻小说肉文语境！
