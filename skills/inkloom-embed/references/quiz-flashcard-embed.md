# 真金题与闪卡的嵌入原则

用户 2026-08-31 确立。适用于真金题（题目+解析）与闪卡两类文件。

## 一、真金题 md 的插入原则

真金题 md 结构：`# 专题标题` → `## 📌 考点必背`（若干 `### N. 小节`）→ 逐题（`##### 题号` + 题干 + `###### 答案与解析` + 解析块）。

### 1. 考点必背区的插入

- 场景 title 与小节标题**语义匹配**（如"哪些程序可以调解"→"### 1. 调解的范围"），Edit 插在小节标题行后（空一行）
- 同一小节标题后**最多 2 张**；溢出场景上移到 `## 📌 考点必背` 标题行后按清单顺序排列
- 无 `###` 小节的文件：全部场景按清单顺序落 `## 📌 考点必背` 标题后
- 匹配规则按**标题关键词**而非序号——专题号在真金题与讲义间可能错位（民诉真金题23督促↔讲义22；刑法动画N↔真金题N-1）

### 2. 题目解析中的插入 —— 首次出现原则（最轻量）

- **同专题内，同一个动图只在第一次遇到该考点的题目中完整展示**；后续题目遇到同一考点不再重复插
- 判断"第一次"：自上而下扫描题目，考点（custom-qb-question-topic-ids 或题干主题）首次出现的那道题，在其解析区插入
- 插入位置：该题"###### 答案与解析"后的**落点/结论块**附近，或题干后——以离考点陈述最近处为准

### 3. 一图多变（推荐，制作侧配合）

同一个考点做 2-3 个不同视角的动图，专题内避免视觉疲劳、强化理解：
- 角度1：标准正视图（基础题用）
- 角度2：带参数标注/关系分析（进阶题用）
- 角度3：极端情况/边界条件（难题用）

实施：考点首次出现→插角度1；同专题第二次遇到→插角度2；第三次→插角度3。变体不足时按 missing-animations.md 补做。

### 4. 真金题思源文档的插入

- 题目区：**题号N末块**锚（= 下一题标题前的块），previousID 插入
- 考点必背区：小节标题锚
- 刑法讲次错位表（动画N↔真金题N-1）：04主体↔03、05行为↔04、06结果↔05、07因果↔06、08主观↔07、09排除违法↔08、10排除责任↔09、11形态↔10、12共同犯罪↔11、13罪数↔12、14体系↔13、15裁量↔14、16执行↔15；02犯罪构成/03犯罪客体无对应讲

## 二、闪卡的插入原则 —— 按知识点插入

- 闪卡是卡片堆（kramdown IAL `custom-dm-card-id`），**按知识点锚定**：场景 title ↔ 卡片正面/背面的知识点语义匹配，插在对应卡片块后
- 动画带模式（备选）：文件开头标题后放该讲全部场景（仅当卡片无明确知识点对应时）
- 背诵卷闪卡文件名"NN 专题N 标题-闪卡" ↔ 讲义动画 ref 专题标题匹配（同真金题，按标题关键词）
- 卡片文件有严格校验器（validator）：插图行只增不改，插完跑 validator 确认不破格式

## 三、覆盖审计配方（判断"哪些文件缺动画"）

1. 全库扫描 `客观/**/20-整理/**.md` 与 `30-闪卡/**.md` 的 `animation-avif/` 计数（按科目分组）
2. 现存动画按 sourceReference 分类（真金题/闪卡/讲义），列每个科目的动画清单
3. 真金题/闪卡文件 ↔ 动画映射按**专题标题关键词**；生成分配清单（JSON），派子智能体并行插入
4. 主线程验收：逐文件 `grep -c animation-avif` 计数 == 分配数、场景跨文件去重、git diff 纯插入（0 删除）
5. 全库死链校验：所有 md 引用对比 InkLoom manifest 场景集合，列出 404 修正或删除
